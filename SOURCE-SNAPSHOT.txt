The complete corresponding source is supplied as WorldWarVR-v0.4.0-beta.5-Source.zip
beside the portable binary. It includes the pinned OpenXR submodule contents,
which GitHub's automatic source archives do not include.

The release Source ZIP replaces this reference with a generated SOURCE-SNAPSHOT.txt
listing the release commit and SHA-256 hashes of the included source files.
The manifest excludes itself to avoid a circular hash dependency.

Component mapping: root native src/ matches the retained tested beta.5 DLL;
root launcher-ui/ retains beta.4 logic with beta.5 metadata. Complete original
sources for the unchanged native helper, including its original native inputs
and pinned dependencies, are supplied under component-source/beta4.

Read CHANGELOG.md and KNOWN-ISSUES.md for actual test scope and remaining issues.
No game files, saves, credentials, customer diagnostics, or Git metadata are included.
