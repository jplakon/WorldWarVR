World War VR v0.4.0-beta.7 is available free for everyone!

This update focuses on jungle foliage. Grass and shrubs with short cutoffs remain visible farther away, and selected dense ground cover and tree profiles retain fuller leaves and detail instead of changing abruptly as you approach. The reported jungle leaf transition passed a local headset check after focused OpenXR Tester work.

The controls, reload, handling and targeted aiming fixes from beta.6 are retained. The accepted gameplay build is shipped unchanged, with complete matching source and checksums in the attachment.

Download the attached Patreon Release ZIP, open it, then extract the Portable ZIP into a new empty folder. Close the old game/launcher first, keep all files together, and run WorldWarVR.exe. Do not merge versions or extract into the game installation. The Source ZIP is optional to play.

GitHub download: https://github.com/jplakon/WorldWarVR/releases/tag/v0.4.0-beta.7

Start with Performance quality; try Recovery if needed. A legitimate compatible World at War 1.7 installation is required. No game files are included.

Low FPS and stutter are still being worked on. Fuller foliage can be demanding; this is not a frame-rate update or a promise of COD4 VR performance. Changes target audited foliage profiles, not every map. Later private performance experiments are not included.

Practical enemy-grenade throwback remains disabled. Existing weapon, keyboard-prompt, startup/runtime and regional compatibility limitations remain; keep a working Regional Compatibility Test1 folder intact. Local/offline Multiplayer is experimental, and online servers are unsupported. See the included Known Issues document for details.

Thanks for testing and sending feedback! Please include the exact ZIP, headset/connection/runtime, map, weapon and steps with reports. Review logs for private information before sharing; no game EXEs, keys or saves.
