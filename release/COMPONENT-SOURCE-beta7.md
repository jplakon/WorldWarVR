The freshly compiled native helper from the development build is not shipped.
The retained production helper above is the one used in the accepted payload;
its matching implementation remains in root source and historical
`component-source/beta4`. Historical version references in that tree and earlier
release records are intentional. Preserve original attribution and licenses.

The Source ZIP includes the full pinned OpenXR contents, all current first-party
source and retained component sources. Autogenerated GitHub tag archives omit
submodule contents; use the complete Source ZIP for corresponding source.
Native input bytes are preserved without Git text conversion. No private
sessions, Tester runtime, game files, customer diagnostics, keys, profiles or
saves are distributed.

Build native code with CMake's Visual Studio 2022 Win32 generator in a fresh
directory, `-DWAWVR_BUILD_TOOLS=OFF`, Release configuration and the Release CTest
suite. Build the self-contained x64 graphical launcher separately using its
pinned project/lock files. Original native PE bytes are retained; identical
compiler output across toolchain paths is not promised. The Regional
Compatibility Test1 launcher change is not included, and no automatic updater
is introduced.
