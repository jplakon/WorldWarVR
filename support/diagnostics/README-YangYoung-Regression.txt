WORLD WAR VR - YANGYOUNG REGRESSION BUILD

This build enables bounded trajectory, final-visible-aim, weapon-pipeline, FX,
frame, and orientation diagnostics for the exact remaining reports. Please use
the normal launcher settings you would use to play, with automatic reload OFF.

Test as many of these as practical and record each result in TEST-NOTES.txt:

1. Unscoped Mosin-Nagant, M1 Garand, and SVT: fire at a nearby and distant
   fixed point and report whether impacts follow the rendered barrel/sight.
2. Scoped Mosin in Vendetta: with enemies visible, grip one-handed, add the
   support hand, look through the scope, release/regrip, and confirm whether
   enemies ever disappear or the scope becomes blank.
3. M1 Garand rifle-grenade variant: confirm manual reload remains enabled and
   report whether the grenade follows the visible launcher direction.
4. Bolt-action clip insertion: watch for any rifle/hand position jump.
5. Mounted gun: hold the aiming controller still while separately moving your
   head and turning stick; report which input, if any, redirects the gun.
6. Hard Landing open area near the rifle-grenade Garand: check both eyes for
   smoke flicker or missing smoke.
7. Pistol two-hand grip: report whether the support hand position is natural.

Procedure:

1. Extract the ZIP to a new folder and run START-DIAGNOSTIC.cmd.
2. Launch Campaign, perform the tests, and add observations to TEST-NOTES.txt.
3. Close the game and launcher, then run COLLECT-DIAGNOSTICS.cmd.
4. Send the WorldWarVR-YangYoungRegression-Diagnostics-*.zip. Short videos of
   any visual/trajectory failure are useful, but the diagnostic ZIP is needed
   even if everything passes.
