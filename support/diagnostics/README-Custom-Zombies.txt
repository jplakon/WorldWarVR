WORLD WAR VR - CUSTOM ZOMBIES DIRECTX CRASH TEST

This build is for the DirectX unrecoverable-error report when a custom Zombies
map is selected through World at War's Mods menu. It collects the VR log,
launcher/runtime details, a metadata-only custom-map inventory, and matching
Windows application-error entries. It does not copy custom-map or game files.

1. Extract the entire ZIP to a new folder. Do not overwrite an older build.
2. Leave your existing custom map installed in its usual location.
3. Connect and wake the headset and start the VR runtime you normally use.
4. Double-click START-DIAGNOSTIC.cmd, then launch Main Menu.
5. Open Mods and select ONE map that previously failed. Try to start it once.
6. If a DirectX message appears, take a screenshot and record the exact map
   name in TEST-NOTES.txt. Do not repeatedly launch after the first failure.
7. Close the error, World at War, and the World War VR launcher.
8. Double-click COLLECT-DIAGNOSTICS.cmd.
9. Send the resulting WorldWarVR-CustomZombies-Diagnostics-*.zip, the DirectX
   screenshot, and the custom map's download link.

For the first test, use UGX Comosea, Sumpf, or Penguin if that is one of the
maps that originally failed. Please test only one map per diagnostic ZIP.
