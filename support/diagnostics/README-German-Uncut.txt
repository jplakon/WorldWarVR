WORLD WAR VR - GERMAN / UNCUT EXECUTABLE COMPATIBILITY INVENTORY

This package does not bypass executable validation and does not attempt to
inject into an unknown game binary. It safely records the exact legitimate
executable identity needed to determine whether a guarded compatibility
profile can be made.

1. Extract the entire ZIP to a new folder.
2. Open WorldWarVR.exe once and select the legitimate German/uncut World at War
   installation folder. It is expected that validation may reject it. Close
   the launcher afterward.
3. Double-click COLLECT-DIAGNOSTICS.cmd.
4. If the game folder was not saved, paste it into the collector when asked.
5. Send the newly created WorldWarVR-GermanUncut-Diagnostics-*.zip file.

The collector records hashes and PE/file-version metadata but does not copy or
upload the executable or any other Call of Duty file.
