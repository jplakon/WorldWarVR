# Launcher artwork provenance

The launcher header and all interface labels are rendered as real XAML text. None of the images documented here contain a game title, game logo, product wordmark, or other text that the application depends on.

## `LauncherBackground.png`

- **Origin:** Created specifically for World War VR with OpenAI's built-in image-generation tool on August 12, 2026.
- **Prompt summary:** An original, nearly black charcoal tactical surface with subtle paper/metal grain, faint invented map-grid and contour markings, sparse scratches, restrained burnt-orange edge wear, a dark center for readable controls, no focal object, no text, no logo, no character, no weapon, and no recognizable real or fictional map.
- **Application use:** Decorative launcher background only. The UI applies its own readability treatment and renders controls and text independently.
- **Rights/provenance note:** This was generated as original launcher artwork. It was not extracted, traced, photographed, or copied from Call of Duty: World at War or any other game. It contains no game executable, texture, map, logo, screenshot, or other game asset.

- **Source file:** `../WorldAtWarVR-Icon.png`

## Release handling

- Keep this provenance record with the development source.
- Include only the final runtime-sized derivatives in the installer payload.
- Lossless metadata cleanup is permitted for release assets; it does not change their visual content or origin.
- Do not replace either image with a screenshot, texture, map, logo, or other asset taken from the game installation.
