# World War VR v0.4.0-beta.3 — First Free GitHub Release

World War VR is now available free on GitHub, with a portable Windows launcher
and complete matching GPL source. **No Patreon subscription is required.**

This public package retains the existing beta.3 binaries. Documentation,
download instructions, and distribution have been updated; this is not an
additional gameplay-fix release or a new hardware-compatibility claim.

## Included beta.3 improvements

- Ordinary firearm shots, predicted impacts, and tracers use the visible
  barrel basis. Focused headset checks covered the Garand, unscoped Mosin,
  SVT-40, and the PPSh-41/SVT-40 sight corrections.
- Controller-aimed mounted guns no longer receive ordinary headset/body-yaw
  catch-up or snap/smooth-turn steering. Headset look remains independent.
- The scoped Mosin isolates its optic-camera visibility from normal eye views,
  preventing the tested two-grip enemy/vehicle disappearance. Its optical axis
  and shot ray match, and scope-active compass/ammunition HUD was restored.
- The exact Campaign Garand/M7 variant has manual eight-round rifle-mode reload
  and Y-button rifle/grenade switching. **M7 grenade mode retains native reload.**
- Physical melee has additional tracking/grip safeguards and a supported
  held-pistol forward jab. Launcher Browse failures are recoverable by pasting
  the game path into the existing field.

Earlier features include 6DOF weapons and two-hand handling, contextual manual
reloads and either-hand actions, physical scopes/grenades, campaign tank and
aircraft controls, satchels/airstrikes, firing vibration, SteamVR orientation
and pause fixes, optional smooth turning/button controls, and unlocked
standard Campaign Mission Select.

## Downloads and installation

- **WorldWarVR-v0.4.0-beta.3-Portable.zip:** download this to play.
- **WorldWarVR-v0.4.0-beta.3-Source.zip:** complete matching source with pinned
  dependency contents; optional to play, provided without an additional fee.
- **SHA256SUMS.txt** and adjacent **.zip.sha256** sidecars: verify downloads.
- **GPL-SOURCE-NOTICE.txt:** corresponding-source and license information.

Extract the Portable ZIP into a **new, empty folder**, keep its files together,
and run **WorldWarVR.exe** after connecting and waking the headset/controllers.
Select your legitimate, compatible **World at War 1.7** installation, choose
Main Menu for Campaign/Zombies, and start with Performance quality.

Do not extract into the game installation or merge old mod packages. There is
no installer. Updates are manual downloads from GitHub Releases, not automatic
launcher updates. GitHub's autogenerated source-code ZIP is not a player package
and does not include ordinary Git submodule contents.

Read the [installation guide](https://github.com/jplakon/WorldWarVR/blob/v0.4.0-beta.3/INSTALL.md)
and [full controls](https://github.com/jplakon/WorldWarVR/blob/v0.4.0-beta.3/docs/CONTROLS.md).

## Beta limitations and test scope

The creator completed the Campaign on evolving development builds leading to
beta.1. Later updates received focused headset and automated/simulator checks,
not another full Campaign replay on the final beta.3 binary. Local testing
does not close reports on other affected headsets.

**Index no-image startup, some Pimax runtime configurations, a newer-build
Rift S aiming regression, regional/uncut executable compatibility, and Custom
Zombies DirectX crashes remain under investigation.** Some unidentified blank
scope, Hard Landing smoke flicker, pause-panel clipping, clip-insertion,
first-launch reload-setting, and interaction-feedback reports still need
reproduction or affected-user confirmation. Random-melee safeguards are not
declared a universal fix.

Local/offline Multiplayer remains experimental. Online Multiplayer and
public/protected servers are unsupported. Quest 2 through Steam Link is
unsupported. See [known issues](https://github.com/jplakon/WorldWarVR/blob/v0.4.0-beta.3/KNOWN-ISSUES.md).

Report reproducible problems through [GitHub Issues](https://github.com/jplakon/WorldWarVR/issues)
with the exact release filename, headset/connection/OpenXR runtime, preset,
map/mission/weapon, reproduction steps, and a fresh WorldWarVR.log if generated.
Remove personal information before posting logs; do not upload proprietary
game executables, map files, keys, or saves.
