WORLD WAR VR - FLAT-LAUNCH REGRESSION DIAGNOSTIC BUILD

This build is for a computer where older and newer World War VR packages now
launch flat after previously working in VR. It records the effective runtime,
isolated launcher settings, relevant renderer settings, and OpenXR startup.

1. Extract the entire ZIP to a new folder. Do not overwrite an older build.
2. Connect and wake the headset and start the VR runtime you normally use.
3. Double-click START-DIAGNOSTIC.cmd.
4. Select the normal World at War folder and the same compatibility setting
   you used when the problem occurred. Select Performance quality.
5. Launch Main Menu once. Do not use the Mods console or change fullscreen
   settings during this test.
6. Wait at least 20 seconds, then enter ordinary Zombies or Campaign once.
7. Close World at War and the World War VR launcher.
8. Double-click COLLECT-DIAGNOSTICS.cmd.
9. Send the newly created WorldWarVR-FlatLaunch-Diagnostics-*.zip file.

Please state whether the desktop image was mono or side-by-side, whether the
headset showed anything, and which OpenXR runtime you expected to use.
